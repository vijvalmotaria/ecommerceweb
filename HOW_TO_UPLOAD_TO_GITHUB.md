# 🚀 How to Upload ShopSphere to GitHub in 2 Minutes (Without Git)

You do **NOT** need Git installed on your computer. Follow these quick steps:

---

## Step 1: Open GitHub and Create a New Repository

1. Go to [https://github.com/new](https://github.com/new).
2. Enter a **Repository name** (e.g. `shopsphere` or `ShopSphere-Ecommerce`).
3. Set the repository to **Public** (or **Private**).
4. **IMPORTANT**: Leave "Add a README file", "Add .gitignore", and "Choose a license" **UNCHECKED** (leave it empty).
5. Click **"Create repository"**.

---

## Step 2: Open the Upload Page on GitHub

Once created, you will see a page with repository setup options.
Click on the link that says:
👉 **"uploading an existing file"** (or click **"Add file" > "Upload files"** in the top right).

---

## Step 3: Drag & Drop Files from the Clean Folder

Open your file explorer to the upload folder:
📂 `D:\Internship project\ShopSphere_Ecommerce_Project\shopsphere_github_upload`

Select **ALL** items inside this folder:
- `backend` (folder)
- `frontend` (folder)
- `.gitignore`
- `README.md`

Drag and drop them directly onto the GitHub browser page!

> 💡 **Why use this folder?**
> This folder contains **only pure source code** (38 files, ~190 KB total).
> - ❌ NO heavy `node_modules` (which would crash the upload)
> - ❌ NO secret `.env` files with database passwords
> - ✅ Fully working `.env.example` templates included
> - Upload finishes in **less than 5 seconds**!

---

## Step 4: Commit the Files

1. At the bottom of the GitHub upload page, under **Commit changes**:
   - Type: `Initial commit - ShopSphere full-stack ecommerce project`
2. Keep **"Commit directly to the `main` branch"** selected.
3. Click the green **"Commit changes"** button.

🎉 **Done! Your project is now live on GitHub with a professional structure!**
